# QuaVo

## Overview

Arbitrum Stylus + Noir Quadratic Voting

A privacy-preserving quadratic voting system that combines Noir's zero-knowledge proofs with Arbitrum Stylus smart contracts. Users can vote on proposals with their voting power calculated quadratically (cost = votes²), while zero-knowledge proofs ensure complete ballot secrecy. 

The system verifies eligibility and prevents double-voting without revealing individual voter indentities.
